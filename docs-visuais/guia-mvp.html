MVP em Um Fim de Semana

Telegram, n8n, Gemini, Google Sheets e um dashboard estático. Sem banco, sem servidor pago, sem multi-tenant. Os arquivos prontos estão no chat — este é o roteiro para ligá-los.

  • Custo R$ 0/mês
  • Tempo ~4 h no primeiro dia
  • Banco uma aba do Sheets
  • Escopo gastos e entradas

00 O caminho da mensagem

  • gastos-ingestao.n8n.jsonO workflow inteiro, pronto para importar. Seis nós.
  • dashboard.htmlA página do dashboard. Um arquivo, sem build.
  • docker-compose.yml + Caddyfile + env.examplen8n com HTTPS automático na VM da Oracle.
  • lancamentos-modelo.csvO cabeçalho da planilha, para importar no Sheets.

01 O bot e o grupo — 15 min

  1. No Telegram, fale com o @BotFather: /newbot, escolha nome e username. Guarde o token.
  2. Ainda no BotFather: /setprivacy → escolha o bot → Disable.
  3. Crie um grupo com você e sua esposa e adicione o bot.
  4. Se o bot já estava no grupo antes do passo 2, remova e adicione de novo — a mudança de privacidade só vale a partir da entrada.
É aqui que 90% das pessoas travam

Com o privacy mode ligado, um bot em grupo só recebe comandos e menções. A mensagem "85 no mercado" nunca chega ao webhook e nenhum erro aparece em lugar nenhum. Se depois de tudo pronto o n8n não disparar, volte aqui antes de procurar em qualquer outro lugar.

Descobrir os três números que o workflow precisa

Depois de subir o n8n (passo 4), abra o workflow, clique no nó Telegram Trigger e use Listen for test event. Mande qualquer mensagem no grupo e leia a saída do nó:

  • message.chat.id — o id do grupo, um número negativo grande
  • message.from.id — o seu id
  • peça para sua esposa mandar uma mensagem e pegue o from.id dela

02 A planilha — 10 min

  1. Crie uma planilha nova no Google Sheets. Renomeie a primeira aba para Lancamentos (sem cedilha e sem acento — o nó do n8n procura exatamente esse nome).
  2. Importe o lancamentos-modelo.csv por Arquivo → Importar → Substituir planilha atual, ou simplesmente cole o cabeçalho na linha 1. As três linhas de exemplo você apaga depois do primeiro teste.
  3. Copie o ID da planilha da URL: fica entre /d/ e /edit.
  4. Arquivo → Compartilhar → Publicar na web → selecione a aba Lancamentos → formato CSV → Publicar. Guarde a URL gerada; é o que o dashboard vai ler.

03 A chave do Gemini — 3 min

Entre no Google AI Studio e gere uma API key. O free tier cobre com folga o volume de um casal — e mesmo se um dia passar para o pago, o modelo gemini-3.5-flash-lite custa US$ 0,30 por milhão de tokens de entrada, o que nesse uso dá centavos por mês.

A chave entra no arquivo .env da VM. O nó do workflow a lê como {{ $env.GEMINI_API_KEY }}, então ela nunca fica salva dentro do workflow — você pode exportar e versionar o JSON sem medo.

04 A VM na Oracle e o n8n — 1 a 2 h

Agora tem Terraform

Os passos manuais abaixo continuam valendo como referência, mas a infra inteira — rede, VM, volume de dados, IP reservado e o cloud-init que resolve o iptables — está codificada no diretório terraform/ entregue no chat. Com ele, make up cria tudo, make stop desliga a VM sem perder nada e make down destrói a máquina preservando o volume e o IP. Leia o README.md de lá e pule direto para 4.2.

4.1 Criar a máquina

  • Crie a conta na Oracle Cloud e escolha a região mais próxima. Instância Always Free: prefira a VM.Standard.A1.Flex (ARM) com 2 OCPU e 12 GB — sobra muito.
  • Se a Oracle responder "out of capacity" na ARM (acontece bastante), use a VM.Standard.E2.1.Micro: 1 GB de RAM roda o n8n, mas crie 2 GB de swap ou ele morre no meio de uma execução.
  • Imagem: Ubuntu 22.04 ou 24.04. Guarde a chave SSH.
  • Na Security List da subnet, libere as portas 80 e 443 de 0.0.0.0/0.
Pegadinha clássica da Oracle

Abrir a porta no painel não basta: as imagens Ubuntu da Oracle vêm com regras de iptables que descartam tudo. Sem isso, a porta 80 fica fechada, o Let's Encrypt não emite o certificado e o Caddy fica em loop — e a mensagem de erro não diz nada sobre firewall.

# na VM, depois do primeiro ssh
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 80  -j ACCEPT
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 443 -j ACCEPT
sudo netfilter-persistent save

# swap, só se você ficou na micro de 1 GB
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

4.2 Domínio grátis

O Telegram só entrega webhook em HTTPS com certificado válido, então IP puro não serve. Crie um subdomínio no DuckDNS apontando para o IP público da VM. Leva dois minutos e é de graça.

4.3 Subir o n8n

# instalar docker
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER && newgrp docker

# suba os três arquivos que estão no chat para ~/gastos/
cd ~/gastos
cp env.example .env
openssl rand -hex 24          # cole o resultado em N8N_ENCRYPTION_KEY
nano .env                     # DOMINIO, GEMINI_API_KEY, N8N_ENCRYPTION_KEY

docker compose up -d
docker compose logs -f caddy  # espere o certificado sair

Abra https://seudominio.duckdns.org, crie a conta de dono do n8n e pronto.

05 Ligar o workflow — 20 min

  1. No n8n: Workflows → Import from File → gastos-ingestao.n8n.json.
  2. Abra o nó Telegram Trigger e crie a credencial com o token do BotFather. O nó Confirmar no grupo usa a mesma.
  3. Abra o nó Gravar na planilha, crie a credencial do Google (OAuth2) e cole o ID da planilha no campo Document.
  4. Abra o nó Triagem e prompt e ajuste as três primeiras linhas: CHAT_ID, MEMBROS e, se quiser, a lista de CATEGORIAS.
  5. Ative o workflow. O n8n registra o webhook no Telegram sozinho.

Mande "85,50 no assaí ontem" no grupo. Em poucos segundos deve aparecer a linha na planilha e um reply do bot confirmando. Depois mande "bom dia" — nada deve acontecer, nem resposta nem linha: é a triagem funcionando.

O que cada nó faz

NóResponsabilidade
Telegram TriggerRecebe todo update do grupo

Por que não usei os nós de IA do n8n

Um HTTP Request direto no Gemini tem menos peças, não depende da versão dos nós LangChain e deixa o responseSchema visível e editável. Quando o parser errar, você mexe em duas linhas de texto e testa na hora — que é exatamente o que você vai fazer nas primeiras semanas.

06 O dashboard — 20 min

  1. Abra dashboard.html e cole a URL do CSV publicado na constante CSV_URL, no topo do bloco de script.
  2. Crie um repositório no GitHub, suba o arquivo como index.html e ligue o Pages em Settings → Pages → Deploy from branch.

A página lê o CSV e calcula tudo no navegador: entradas, saídas, saldo, taxa de poupança, disponível por dia no mês corrente, gastos por categoria, os últimos 12 meses e a lista de lançamentos. Não há nada para manter — se você mudar a planilha, o dashboard muda junto.

Por que GitHub Pages e não abrir o arquivo direto

Aberto pelo Finder (file://), o navegador bloqueia a leitura do CSV do Google por política de origem. Precisa estar servido por http ou https — GitHub Pages, Netlify ou Cloudflare Pages, todos gratuitos, resolvem. Se preferir só testar rápido no Mac: python3 -m http.server na pasta do arquivo.

Um detalhe de privacidade que vale saber: "publicar na web" gera uma URL pública, sem senha. Ninguém adivinha o endereço, mas quem tiver o link vê os dados. Para uso pessoal é aceitável; se incomodar, o caminho é trocar a leitura por uma Apps Script Web App com acesso restrito à sua conta.

Deixado de fora de propósito, na ordem em que faz sentido acrescentar depois que registrar virar hábito:

  1. Áudio e foto de comprovante — um nó antes do Gemini que baixa o arquivo do Telegram. É o que mais aumenta o uso no dia a dia.
  2. Resumo diário — um segundo workflow com Schedule Trigger às 21h, lendo a planilha e mandando uma linha no grupo.
  3. Correção por botão — teclado inline para trocar a categoria sem abrir a planilha.
  4. Perguntas em linguagem natural — aí sim o Sheets começa a apertar, e é o sinal de que vale a pena o Postgres do blueprint original.
O critério para a próxima fase

Não acrescente nada disso enquanto vocês dois não passarem duas semanas seguidas lançando sem falhar. Se o hábito não pegar, nenhuma funcionalidade extra salva o projeto — e você terá descoberto isso com um fim de semana de trabalho, não com dois meses.
